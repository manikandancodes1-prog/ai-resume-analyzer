# 🚀 AI Resume Scoring Web App

A premium AI-powered Resume Analyzer that extracts skills from resumes, groups them (Frontend / Backend / Tools), scores candidates, and displays results in a modern ultra‑premium UI.

---

## ✨ Features

* 📄 Upload Resume (PDF)
* 🧠 Automatic Skill Detection
* 🧩 Skill Grouping (Frontend / Backend / Tools)
* 📊 Resume Score System
* 🪄 Ultra Premium Glassmorphism UI
* ⚡ Fast React Frontend
* 🧩 PDF.js Integration
* 📥 Downloadable Reports (Optional)
* 🎨 Smooth Animations & Modern Design

---

## 🛠 Tech Stack

**Frontend**

* React.js
* Tailwind CSS
* PDF.js
* Lucide Icons

**Backend (Optional Upgrade)**

* Node.js
* Express.js
* AI / NLP APIs

---

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone (https://github.com/manikandancodes1-prog/ai-resume-analyzer.git)
cd ai-resume-analyzer
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start Development Server

```bash
npm start
```

Open browser → `http://localhost:3000`

---

## 📤 How to Upload Resume

1. Click **Upload Resume**
2. Select PDF file
3. App extracts text & detects skills
4. Skills grouped into categories
5. Resume Score displayed
